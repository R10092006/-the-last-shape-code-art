# THE LAST SHAPE — A Digital Survival Experience

An original Squid Game-inspired code-art experience built with HTML, CSS and JavaScript Canvas.

## Features
- Animated generative arena background with particles, perspective grid and glowing symbols
- Responsive cinematic landing screen
- Interactive honeycomb challenge with pointer-based tracing
- Countdown, progress feedback, win/lose states and replay
- Optional synthesized sound effects using the Web Audio API
- Artist's note explaining the creative concept

## Run locally
1. Download or clone this repository.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Click **ENTER THE GAME** and trace the triangle inside the cookie.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — Canvas animation and interaction
